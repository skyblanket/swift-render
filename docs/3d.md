# 3D with Scene3D

`Scene3D` puts true 3D inside any scene. It renders a SceneKit scene offscreen with
`SCNRenderer`, at the frame's real pixel size, and hands the result back as an image. The image
composites with SwiftUI, Metal shader effects, Timeline transitions and `PostFX` like any other
view. Everything is driven by `t`: you describe the scene for this frame, and the engine builds
it.

The demo is `Showcase3D`. It's a titanium device with a live SwiftUI screen, studio light, a dolly
and depth of field. To look at it:

```bash
swift run swift-render check Showcase3D
swift run swift-render render Showcase3D --out out/showcase3d.mp4
```

## A product shot in 25 lines

```swift
import SwiftUI
import SwiftRender

public struct Hero3D: RenderScene {
    public static let defaultDuration: Double = 6

    @MainActor public static func body(at t: Double, duration: Double) -> some View {
        let center: Vec3 = [0, 0.08, 0]                                  // metres
        let cam = Camera3D.dolly(t,
            from: .orbit(target: center, distance: 0.7, azimuth: -20, elevation: 14, fov: 24),
            to:   .orbit(target: center, distance: 0.5, azimuth: 4, elevation: 10, fov: 24),
            start: 0, end: duration)
            .focused(on: center, fStop: 2.8)

        return Scene3D(camera: cam, environment: .studio, background: .view { MyBackdrop() }) {
            Slab3D(width: 0.0716, height: 0.1476, depth: 0.0078, cornerRadius: 0.0112,
                   screen: .screen(.view(width: 390, height: 844) { MyAppScreen(t: t) }))
                .material(.metal(Color(white: 0.6), roughness: 0.34))
                .rotation(y: Motion3D.easedTurntable(t, degreesPerSecond: 12))
                .position(center)
            Floor3D(material: .shadowCatcher())
            Light3D.directional(intensity: 900, from: [-0.1, 1, -0.2], at: center, shadow: .soft(extent: 0.25))
        }
    }
}
```

## The API

A scene is a list of `Node3D` values, built in a `@Scene3DBuilder` closure that supports `if`,
`switch` and `for`. Every primitive conforms to `Object3D`, so the modifiers read the same on any
of them.

| Node | What it is |
|---|---|
| `Box3D(width:height:length:chamfer:)`, `Sphere3D`, `Plane3D(…, cornerRadius:)`, `Cylinder3D`, `Cone3D`, `Torus3D`, `Capsule3D` | Primitives |
| `Slab3D(width:height:depth:cornerRadius:edgeRadius:screen:screenInset:)` | A rounded device slab (procedural mesh with smooth rounded edges). `screen:` adds an inset rounded display panel. Material elements are front, back and sides. |
| `Text3D("Hi", size:depth:font:weight:chamfer:)` | Extruded text, centred. `size` is the font size in scene units. |
| `Model3D("models/x.usdz", fit: .height(1), anchor: .bottom)` | USDZ, USD, OBJ, SCN, DAE: anything `SCNScene(url:)` reads, resolved through `AssetPaths`. Loaded once per process and reloaded when the file changes. |
| `Floor3D(reflectivity:falloff:material:)` | An infinite floor at y = 0 |
| `Light3D.directional / .spot / .omni / .area / .ambient`, `Light3D.studioRig(target:size:)` | Lights. They shine along −Z and `look(at:)` their target. |
| `Group3D { … }` | A transform-only parent |

**Modifiers:** `.position(x, y, z)`, `.offset(_:)`, `.rotation(x:y:z:)` (degrees, Z then X then Y,
so `y:` is a turntable spin), `.rotated(_:axis:)`, `.look(at:)`, `.scale(_:)`, `.material(_:)`,
`.materials([…])` (one per element), `.opacity(_:)`, `.hidden()`, `.castsShadow(_:)`,
`.renderingOrder(_:)`, `.named(_:)`, `.children { … }` and `.part(_:_:)`.

**Model parts by name.** `.part("Arm") { $0.rotated(30, axis: [0, 0, 1]).material(.metal()) }`
edits a named node inside a model. Transforms are relative to the part's rest pose, and every
frame starts from that rest pose, so an override never sticks. Part edits are `offset`, `rotated`,
`scaled`, `hidden`, `opacity` and `material`.

**Materials** are physically based (`Material3D`). You can set base color, metalness, roughness,
emission (with an intensity above 1 for bloom), normal and ambient-occlusion maps, clear coat,
opacity, double-sided and tiling. Every slot takes a `Texture3D`: `.color`, `.image(path)`,
`.cgImage` or `.view(width:height:scale:) { AnySwiftUIView }`. A view texture is rendered at the
current frame, so your app's screens animate on the device. The presets are `.plastic`, `.matte`,
`.metal`, `.glass`, `.emissive`, `.unlit`, `.screen` (a glowing texture under glossy cover glass)
and `.shadowCatcher`.

**Stage:**

- `environment:` is image-based lighting. Use `.studio` for the default procedural studio: a
  float HDR with a big overhead soft box, two strip lights, a key panel and a floor bounce.
  `.studio(intensity:rotation:)` adjusts it. `.file("hdri/room.exr", intensity:, rotation:)`
  loads `.hdr`/`.exr` as float, and `.none` turns it off.
- `background:` can be `.color(…)` or `.view { SwiftUI }`. A view background is a camera-locked
  card inside the 3D frame, so depth of field blurs it as distant and shadow-catcher floors darken
  it. `.transparent` gives alpha 0 for compositing over SwiftUI beneath. `.environment` shows the
  environment image itself.
- `fog: Fog3D(color:start:end:exponent:)`.
- `effects: Effects3D(hdr:exposure:bloom:ambientOcclusion:vignette:saturation:contrast:)`.
  `.cinematic` adds gentle bloom and contact occlusion.
- `antialiasing: .x4` (default), `.x2` or `.none`.

**Camera.** `Camera3D(position:target:up:fov:roll:near:far:depthOfField:orthographicScale:)` is a
plain value: interpolate it, spring it, or compute it from `t`.

```swift
Camera3D.orbit(target: c, distance: 1.2, azimuth: Motion3D.turntable(t, degreesPerSecond: 10), elevation: 12)
cam.focused(on: c, fStop: 2)          // focus distance tracks the camera as it moves
cam.dollied(0.2)                      // push in along the view axis (focus follows)
Camera3D.lerp(a, b, p)                // p unclamped, so springs may overshoot
Camera3D.dolly(t, from: a, to: b, start: 1, end: 4, easing: Ease.easeInOut)
Camera3D.spring(t, from: a, to: b, start: 1, response: 1.2, dampingFraction: 0.85)
Motion3D.turntable / easedTurntable / oscillate / hover   // angles in degrees, all pure in t
```

Units: by convention 1 unit is 1 metre. That keeps depth of field (a real lens model: `fStop`,
focus distance), light falloff and shadow softness sensible. A phone is about 0.07 × 0.15 × 0.008.

## How it works, and what makes it deterministic

Each frame, `Scene3D`'s description is reconciled onto a cached SceneKit graph. A node keeps its
SceneKit object while its kind (geometry, model file, light) stays the same, and every property
of every node is set from the description again, so nothing carries over from the previous frame.
SceneKit's own clock never runs:

- The scene is paused, physics is stopped, and loaded models lose their embedded animations,
  actions, particle systems, physics bodies and cameras.
- `snapshot(atTime:)` always gets `0`. Jittering and temporal antialiasing are off. The camera's
  exposure adaptation and motion blur, which both read previous frames, are off.
- Implicit `SCNTransaction` animations are disabled.

**Measured** (Apple silicon, macOS 26, tests in `Tests/SwiftRenderTests/Scene3DTests.swift`):

- The same `t` rendered twice is **bit-identical**.
- A frame doesn't depend on the frames rendered before it. It's bit-identical after rendering
  other times first, which is what scrubbing, `--range` and `--jobs` chunks rely on.
- Separate processes rendering the same frame are bit-identical (3 runs of `frame Showcase3D
  --at 5`, same PNG hash).
- **Not bit-exact:** if the SceneKit scene is *re-created* inside one process (after cache
  eviction, `Scene3D.purgeCaches()`, or a Studio hot reload), SceneKit re-seeds the sampling noise
  it uses for soft shadows, SSAO and depth of field, and it has no API to fix that seed. The test
  asserts PSNR ≥ 45 dB. Measured values were about 80 dB to ∞ without SSAO and about 49 dB with
  SSAO and depth of field together. That is invisible, but it's not bit-exact. If you need exact
  pixels, render in a fresh process, as `render` and `render --jobs` already do.

## Performance

Cached across frames: the Metal device, one shared `SCNRenderer`, one SceneKit scene per `Scene3D`
id (LRU of 8), meshes by description, model templates by file stamp and environment maps.

`Showcase3D` at 1920×1080, release build, Apple silicon, measured with `SR_3D_STATS=1`, which
prints the mean Scene3D cost:

| | |
|---|---|
| 3D layer (reconcile, 936×2026 SwiftUI screen texture, SwiftUI backdrop, 4× MSAA, DOF, readback) | **≈18–19 ms/frame** |
| Whole frame (plus SwiftUI title, PostFX, encode), serial `render` | ≈22 ms/frame (600 frames in 13.0–13.9 s) |
| `render --jobs 4` | 600 frames in 7.9 s (≈13 ms/frame effective) |
| Studio serve host preview at 960 px | ≈68 fps (host 14 ms/frame) |

Cheaper frames come from `antialiasing: .x2`, no depth of field, smaller view textures
(`scale: 1.5`), and leaving out `ambientOcclusion`.

`render --jobs` works unchanged. Every chunk is its own process with its own renderer, and frames
don't depend on history. In Studio, Scene3D renders in the serve host like any other view.

## Gotchas and limits

- **Give each `Scene3D` that is visible at the same time its own `id:`** when they come from the
  same call site (a `ForEach`, a helper). The default id is the file and line.
- **Depth of field is SceneKit's gather blur.** At low `fStop`, bright edges bleed a soft glow
  onto the background. f/2.8 and up keeps it subtle. For a transparent background, DOF and bloom
  can't spread onto the SwiftUI layers beneath, because SceneKit blurs color but not alpha. The
  engine clamps color to alpha so nothing glows, but blurred silhouettes then have hard alpha
  edges. Use `background: .view { … }` when the camera uses depth of field.
- **Shadow catchers** (`.shadowCatcher()`) work over `.color` and `.view` backgrounds and over
  `.transparent` for compositing. Shadows render in deferred mode. A thin object lit edge-on casts
  a thin shadow, so light it from behind or above to show it on the floor.
- **Very glossy specular is capped.** Roughness is clamped to ≥ 0.06 and clear-coat roughness to
  ≥ 0.1, and every material gets a fragment modifier that drops non-finite values and caps
  radiance at 48. Without these, a specular peak overflows the half-float DOF pass and smears a
  black block across the edge. A material that already has its own fragment shader modifier is
  left alone.
- **No ray tracing.** SceneKit is a rasteriser, so there's no refraction (`.glass` is clear-coated
  transparency), no caustics and no GI beyond image-based light and SSAO. Area lights don't cast
  shadows. Pair them with a shadow-casting directional or spot key.
- **Embedded model animations are not played.** They would run on SceneKit's clock. Pose parts
  from `t` with `.part(_:_:)`. Skinned and skeletal animation isn't exposed. Particles and physics
  are off.
- **OBJ files with several `o` objects load as one node** (that's how ModelIO reads them). For
  named parts, use USDZ or SCN.
- **SwiftUI inside textures and backdrops** renders in its own `ImageRenderer`, so it doesn't see
  the scene's `renderContext`. Pass what it needs.
- **View backgrounds go through the camera's tone mapping** (HDR is on by default), so colors can
  shift slightly from the same view drawn in 2D. Use `effects: Effects3D(hdr: false)` for exact
  colors.
- **Metal is required.** Without a GPU, `Scene3D` draws nothing and prints one warning.
- **SceneKit is in maintenance mode at Apple.** It ships and is stable on macOS 14+. Scenes only
  touch the `Scene3D` value API, so a RealityKit backend could replace it later without changing
  scenes.
